# 配對高手 Mobile App

這是原始配對遊戲的手機版 PWA。保留單人配對、雙人對戰、拼字、聽寫、自建字庫與最佳紀錄，並新增：

- Android／iPhone 主畫面安裝
- 全螢幕 App 顯示
- 離線遊玩
- 320px 起的雙欄觸控牌面
- iPhone 安全區與 Android 手勢列適配
- 鍵盤焦點與螢幕閱讀器標示

## 英文與中文意思配對

選擇「配對」後，可在「配對內容」切換「原有配對」或「英文 ↔ 中文意思」，單人與雙人皆可使用。34 個內建字庫的 709 組項目提供補充的繁體中文常用義；教師提供的英文定義與動詞三態維持原樣，中譯不是教師提供的標準答案，建議由教師或家長複核。

「我的字庫」可修改每組的中文意思，自建字庫也能直接填英文與中文。已有兩欄英中資料可直接使用；尚無中譯的自訂項目不會抽入中文配對，至少需兩組不同中文意思才能開始。同一輪不放入中文意思完全相同的兩組。原有與中文配對的最佳時間分別保存，遊玩紀錄會註明配對內容；首次連線更新後可離線使用。

## 玩家遊玩紀錄

開始前填寫玩家名稱；雙人對戰各自填寫名稱。「遊玩紀錄」可依名稱及遊戲類型查詢，每頁 20 筆，顯示開始／結束時間、字庫、設定、完成題數、失誤、分數、遊玩秒數及對戰勝負。配對、拼字、迷宮追逐、打地鼠均會記錄，重玩另開新紀錄，中途結束與重新整理也保留已保存的紀錄。

紀錄自本功能上線後累積，舊版本沒有保存逐次遊玩資料，無法回補。相同名稱視為同一位玩家；這是裝置本機紀錄，清除網站資料會移除紀錄，不會同步其他裝置。若儲存已滿或資料損壞，畫面會顯示警告並保留原有資料。

- L3&L4 動詞三態共 84 組（原形、過去式、過去分詞）
- L6 Week 1、2、3、4、5、7、8、9、10、12、13、14、15、22、23、24，共 255 組單字與英文定義
- L6 動詞三態共 115 組（原形、過去式、過去分詞）
- 資料來源為教師提供的 L3/L4 與 L6 2026-1 Word Bank、Definition Bank 與 Verb List

## 手機安裝

在手機瀏覽器開啟上方網址：

- Android Chrome：點頁面上的「安裝 App」，或瀏覽器選單 →「安裝應用程式」。
- iPhone Safari：分享 →「加入主畫面」→「新增」。

安裝後可直接從手機主畫面全螢幕啟動；第一次完整開啟後，沒有網路也能玩。

## 本機預覽

在此資料夾啟動任一靜態網站伺服器，不要直接雙擊 `index.html`，因為瀏覽器不允許 `file://` 頁面註冊離線服務。

例如已安裝 Node.js 時：

```powershell
npx serve .
```
